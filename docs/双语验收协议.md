# 中英双语统一验收协议

这是M4的双语扩展。原中文验收记录保留为历史，不用于替代新版结果。中文、英文分别执行冻结20例，以及T01/T06/T10/T15/T18各三次，共40个主场景、30个关键执行（关键首次计入主场景），合计60个执行单元。其中两种语言各有一个T09直接工具边界，不冒充模型在线任务。

门槛：每种语言主轮至少18/20、关键各15/15、无已显示的事实或来源阻断项；代码、配置、数据及评分脚本整轮冻结。英文回答必须是英文，中文回答必须是中文；原文引用、ID与结构化枚举可保留原语言。正确拒绝未校验文字仍算任务未完成，不能当合格回答。

对照同一P001、2026-10-23、America/Chicago。两种语言均检查精确记录、单位、样本、事件、前后方向、时间区间、图表及来源；英文词汇评分只作同义表达匹配，不放宽数据要求。英文日期包含式终日转换由应用执行，不能据此宣称模型独立日期算术正确。

使用一个真实本机模型和同一套工具。每个任务新会话，多轮任务内部沿用会话；单轮240秒、多轮合计360秒。程序记录、图表及业务回执按标注的系统产物计完成，不算模型文字分析。T09直接检查伪造、跨会话和过期ID。

另用独立虚构数据库上传一个冻结英文TXT，不改变主库四份报告；通过真实本机embedding建立索引。分别以中英文提问，要求有原文定位并正确说明缺测日期留空，两次都须通过。源文件为tests/fixtures/english_report.txt。

界面用真实浏览器验证语言切换、英文提问与英文回答、原始记录/图表及来源；离线测试覆盖中文回归、英文日期/药名、暂停恢复、语言切换、负例及事实校验。最终由Codex逐条复核全部展示结果与来源，保存manual_review.json，不冒充外部或临床审核。

失败、超时或未执行项目不得算通过；修复后新建完整运行目录，保留旧轮。测试替身仅用于自动化检查。此次不验证所有自然语言、所有模型、真实患者或临床效果。

绘图时模型可选择query_1等本任务应用句柄，应用在执行前绑定到真实result_id并在trace记录model_source_handle；不模糊纠错或接受其他会话来源。直接工具调用仍拒绝伪造/过期/跨会话ID。

简单latest与series查询成功后可由明确标注的record_receipt显示真实测量、时间、单位、条件与引用，避免模型重新抄数值或多余追问。模型仍选择工具和参数；需要分析、解释、统计或完整历史的请求继续模型回答与事实校验。这些回执计系统完成，不计裸模型文字生成准确率。

追问不是事实结论：缺失字段问题和选项由应用的中英文类型模板生成，事件说明只取已读取的真实事件。模型原始追问只保留在技术trace，不作为个人测量、无数据或查询完成的依据。不得在未执行查询时通过追问声称查询无结果。

英文源文的明确定性声明可作有限、受控的跨语言等价匹配；不能因此添加原文未支持的全文缺失断言。引用行号只有与已引用来源的实际起止行精确一致时才作为定位元数据处理，不是对任意数字或测量值的豁免。--report-smoke只运行英文源文双语专项，明确标为smoke_only，不得算正式通过率。
