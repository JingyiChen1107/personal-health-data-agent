# 使用与交接

这是v0.9.0单机课程原型。全部数据虚构，参考日固定2026-10-23、America/Chicago。中文19/20、关键15/15；英文18/20、关键15/15；英文报告双语检索2/2；275项自动化测试通过。未完成场景与原因见M4。设计与正式结果见[M4](../docs/M4_质量验证与交付.md)。

## 一、原桌面项目直接使用

项目主目录：当前克隆目录（下文`${PROJECT_ROOT}`指该目录）。

1. 演示前双击“演示前检查.command”，检查数据、两种模型、报告索引与网页。
2. 平时双击“启动本地Agent.command”，打开 http://127.0.0.1:8501/ 。
3. 一次提交单一指标任务。刷新可能建立新会话；在同一页面继续输入可恢复追问，点击“新建会话”开始独立上下文。

现有环境、模型、数据和会话保留；本地推理不需要API密钥。检查脚本只在数据库缺失时初始化；不要覆盖已有.env，也不要为启动程序重置数据库。

## 二、新环境安装

已验证环境为macOS arm64、Python 3.12。需要安装Python 3.12和官方Ollama CLI；其他平台尚未做完整验收。安装入口：https://ollama.com/download 。交付包不包含运行程序、模型权重、虚拟环境或任何真实密钥。

解压到独立文件夹后，在该目录执行：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
.venv/bin/python scripts/prepare_demo.py --start --initialize
```

首次预检可能提示模型与索引未就绪。这时本机服务已经启动，继续下载两种固定模型：

```bash
OLLAMA_HOST=127.0.0.1:11435 ollama pull qwen3.5:4b-q4_K_M
OLLAMA_HOST=127.0.0.1:11435 ollama pull embeddinggemma:300m
.venv/bin/python scripts/prepare_demo.py --start --initialize --reindex
```

本地推理不需要OpenAI或Hugging Face密钥。首次安装与下载需要联网；模型与embedding推理走本机。脚本优先使用项目.runtime/ollama/ollama，其次使用PATH中的官方ollama。模型保存在项目.runtime/ollama/models。索引与生成结果保存在项目文件夹内。

## 三、演示流程

先运行演示前检查；下面时间仅为主讲安排，本地推理延迟会波动。在线调用若失败，应展示真实错误，不能用预录结果冒充成功。

| 时间 | 操作 | 展示重点 |
|---|---|---|
| 0:00–0:40 | 打开本地页面，介绍虚构标记、参考日期和本机模型 | 一个主Agent，五个工具；无云端推理密钥要求 |
| 0:40–1:40 | 新会话：“我最近一次血糖是多少？” | 6.9 mmol/L、G032、条件未知；展开来源核对时间与记录 |
| 1:40–2:40 | “2026年10月1日到10月15日的空腹血糖记录是什么？” | 包含15日，8条记录，表格保留ID、测量条件和单位 |
| 2:40–3:40 | “画出2026年10月1日至23日的体重趋势。” | 模型先查后画，7点；明确工具回执；下载PNG/SVG/JSON |
| 3:40–5:10 | 新会话：“帮我看看血压。”→“最近一次就好。”→“那2026年9月23日最近一次呢？” | 真正暂停恢复，同次高低压配对；126/82与136/87 |
| 5:10–6:40 | 新会话：“2026年10月1日二甲双胍调整前后14天空腹血糖有什么变化？” | 先确认E007；8对8，均值7.95与7.00；不推断药物因果 |
| 6:40–7:40 | “R003报告对血糖记录整理是怎么说的？” | 本地RAG，原文片段、文件与行号；数字不替代最新结构化记录 |
| 7:40–8:40 | 新会话：“完整检查R002，是否提到了LDL及其别名？” | 全文扫描与语义片段的区别，否定结论有明确范围 |
| 8:40–9:40 | “先读取R004，再告诉我最近一次血糖，按数据库结果回答。” | 检查真实调用先检索再查询数据库；如文字未通过校验，明确展示失败及G032原始事实，不把拒绝生成说成完整回答成功 |
| 9:40–10:00 | 打开M4验证与交付文档 | 实际通过率、失败项、代码哈希与局限；不宣称临床可靠性 |

本机推理时间可能波动，建议主讲挑选四个场景完成5分钟版，其余用于答疑。课程演示中的精确值只适用于提供的冻结数据；不连接真实患者数据，不提供诊断或用药建议。

## 七、中英文使用与验收

侧栏“语言 / Language”在中文/English间切换界面。输入中文问题得到中文回复，英文问题得到英文回复；事件ID、数字选项沿用暂停任务的语言。API可通过agent.run(question, language="en")或language="zh"显式选择。源文、真实ID和已有历史消息保留原语言，不会生成伪造的翻译证据。

英文例子：

- What is my latest blood glucose?
- List my fasting glucose records from October 1 to October 15, 2026.
- Plot my weight from October 1 to October 23, 2026.
- Compare fasting glucose 14 days before and after the metformin change on October 1, 2026.
- What does report R003 say about organizing blood glucose records?

语言与单位标签变化不等于单位换算；使用工具标准单位。日期例子覆盖ISO、已测试的英文月份写法与上一自然年，不能假设所有自然语言日期格式都已验证。最新查询只返回最近记录，不证明历史只有一条。

English: Select **English** in the sidebar. Ask the examples above, or continue a paused clarification in the same session. Enter **cancel task** to cancel. Replies follow your question language, while original source quotations keep their language. The demo reference date is fixed at **2026-10-23**, America/Chicago. Do not upload real patient data into this course prototype.

The final acceptance runs the same 20 scenarios in each language, with each core scenario repeated three times, plus two questions against an uploaded synthetic English TXT. Read M4 for actual pass counts and unresolved tasks. A rejected or paused response is not counted as a completed answer. No clinical validation or production-security certification is claimed.
